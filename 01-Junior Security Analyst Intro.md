# Security Analyst Journey

# What is a Security Analyst?

A **Security Analyst** protects an organization's systems, networks, and data from cyber attacks.

They are usually the **first line of defence** against attackers.

### Main Goal

* Detect attacks
* Investigate alerts
* Respond quickly
* Reduce damage
* Keep the organization secure

# What is a SOC?

**SOC = Security Operations Center**

A SOC is a team that continuously monitors and protects an organization's IT infrastructure.

It usually works **24 hours a day, 7 days a week (24/7).**

# Junior Security Analyst (SOC Level 1)

This is usually the **entry-level cyber security role.**

Main responsibilities:

* Monitor security alerts
* Investigate suspicious activity
* Escalate serious incidents
* Document findings
* Work with senior analysts

Think of them as the **first responder** in cyber security.


# Daily Duties

As a Junior Security Analyst, you may:

### 1. Monitor Security Alerts

Continuously check alerts from security tools.

Example:

* Malware detected
* Failed login attempts
* Suspicious network traffic


### 2. Investigate Alerts

Determine whether an alert is:

* False Positive
* Real Attack

Example:

Antivirus detects a suspicious file.

You investigate whether it is actually malicious.

### 3. Participate in Team Discussions

SOC analysts regularly discuss:

* New threats
* Recent attacks
* Detection improvements
* Incident reviews

### 4. Work with Other Teams

Coordinate with:

* IT Team
* Network Team
* Incident Response Team
* Management

Security is a team effort.

### 5. Keep Learning

Cyber threats evolve every day.

Security analysts must continuously learn about:

* New malware
* Phishing techniques
* Vulnerabilities
* Defensive tools

# SOC Team Roles

## 1. Junior Security Analyst (SOC Level 1)

Responsibilities:

* Monitor alerts
* Initial investigation
* Escalate serious cases

## 2. Senior Security Analyst

Responsibilities:

* Handle complex incidents
* Help junior analysts
* Perform deeper investigations


## 3. SOC Engineer

Responsibilities:

* Configure security tools
* Improve detections
* Reduce false positives
* Maintain SOC infrastructure

## 4. SOC Manager

Responsibilities:

* Manage SOC team
* Report security status
* Coordinate operations
* Improve SOC performance

## 5. Incident Responder

Responsibilities:

* Respond to major incidents
* Contain attacks
* Remove threats
* Recover systems

# Common Incidents You May Handle

As a Junior Security Analyst, you may investigate:

### Malware Infection

A user's computer is infected with malicious software.

### Phishing Attack

Employees receive fake emails trying to steal:

* Passwords
* Banking details
* Company information

### Data Stealer

Malware that steals:

* Passwords
* Browser cookies
* Saved credentials
* Cryptocurrency wallets

### Ransomware

Malware encrypts files and demands payment.

### Suspicious Login

Someone logs into an account from an unusual location.

### Network Attack

Examples:

* Port scanning
* Brute force attacks
* Command and Control (C2) communication
